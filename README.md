# URL Shortener 🔗

A modern and lightweight URL shortening application that transforms long URLs into short, shareable links. Built to provide fast redirection, simple link management, and a clean user experience.

---

## 🚀 Features

* Shorten long URLs instantly
* Generate unique short links
* Fast redirection to original URLs
* Simple and clean UI
* Responsive design for mobile and desktop
* Persistent storage for shortened URLs
* Easy to deploy and extend
* User authentication
* Custom short URLs
* Analytics dashboard
* Click tracking

---

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/RelaxedRhythm/url-shortener.git
cd url-shortener
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the root directory.

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
BASE_URL=http://localhost:5000
```

### 4. Start the Server

```bash
npm start
```

For development:

```bash
npm run dev
```

---

## 🌐 Usage

1. Open the application in your browser
2. Paste a long URL
3. Click **Shorten**
4. Copy and share the generated short URL
